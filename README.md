# CINCO™ Pocket Watch

A fictional parody pocket watch, made for Nick. A CINCO Corporation Product. Time, Now With More Time.

Nothing is for sale. No card is charged, nothing ships, no number is dialled, and nothing links out.

Live: https://mandeerinfinity.github.io/cinco-pocket-watch/

- Canvas-rendered brass pocket watch: engraved hinged lid, crown (tap = lid, drag = wind, long-press = pull and set), swaying chain, open-heart and full skeleton movement, subdials, moon phase, power reserve.
- Digital mode: nixie tubes or LCD.
- Winding and run-down, ticking, hourly strike, minute repeater, stopwatch, timer, alarms, world time incl. Gerald Standard Time.
- CINCO Time Adjustment Services, recalls, warranty, infomercial, hotline with original hold music, achievements, finishes (plus a secret one), PWA/offline, reduced motion.
